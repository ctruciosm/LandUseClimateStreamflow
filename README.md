# LandUseClimateStreamflow

This repository contains tha data and codes used in _Impacts of land use change and climate variability on the streamflow of a south american's basin: A comparative analysis between scenarios_ (Machado et al. 2026+)

- Folder `data` contains all data used in the paper
- `raps_ita.R` perform the RAPS and ITA analysis
- `residuals.R` analyses the residuals (residuals = Medido - Simulado)


## References

- Machado, Ronalton Evandro, Tárcio Rocha Lopes, Sergio Nascimento Duarte, and Carlos Trucíos. (2026+). “Impacts of Land Use Change and Climate Variability on the Streamflow of a South American’s Basin: A Comparative Analysis Between Scenarios.” _Submitted_
